# LangChain

Materiais de aula em PDF sobre LangChain.

## Aulas

- `Aula-01-Introdução-a-LangChain.pdf`: visão geral do LangChain e seus conceitos base.
- `Aula-02-Document-Loaders.pdf`: carregamento de documentos e fontes de dados.
- `Aula-03-Prompts.pdf`: construção e organização de prompts.
- `Aula-04-Chains.pdf`: encadeamento de etapas e pipelines.
- `Aula-05-Integração-com-LLM.pdf`: integração com modelos de linguagem.
- `Aula-06-Criação-de-Agents.pdf`: criação de agentes e tomada de decisão.

## Uso no projeto

- Base de apoio para a camada de orquestração com LangChain.
- Referência para loaders, prompts, chains e agents.
- Complementa os fluxos de LangGraph quando o grafo usa nós com prompts, ferramentas e chamadas de modelo.
